# T2 — exact optimal-control solution with nonzero convection (ex21)

**Result: PASS.** This is the first test of ex21 against an exact optimal-control
solution, with state, adjoint and control all known, at `v ≠ 0`. It is a
**source-inspired** construction (the manufactured-solution idea of Leveque &
Pearson §5.1), **not** a reproduction of any published example.

Measured results:
- Q2 converges at order **3.00** in space (state over the whole interval; adjoint
  and control on `t ≤ T/2`; nx up to 64).
- Crank–Nicolson converges at order **1.97** in time for the adjoint and control
  in the full `L²(0,T;L²)` norm. The state reaches **2.22**; its final-time error
  reaches **1.97**.
- Backward Euler converges at order **1.00** in time.
- The algebraic checks hold: exact transpose, FD gradient 5e-13, Hessian symmetry
  4e-14, independent march ≤ 4e-13, relative KKT residuals ≤ 5e-12.

One expected, documented DTO effect appears: the **terminal adjoint slot** of CN.
It does not degrade the global second order, and it is quantified in §6.

Code: `include/ExactOcBenchmark.{hpp,cpp}` (new, opt-in run mode `--exact-oc`).
No solver, assembly or default changed.

Data:

- `logs/gates/verify_convection_t2_*.log`

## 1. Sign convention (derived, not copied)

ex21 solves the dt-scaled DTO KKT system (`Solver.hpp`):

    E Y + (η²/α_u)(I⊗N) Λ = rhs_y,      −α_t (W⊗M_ω) Y + Eᵀ Λ = −α_t (W⊗M_ω) Y_d,      u = −(η/α_u) λ.

This system is the stationarity system of the discrete Lagrangian

    𝓛 = J(Y, U) − dt Λᵀ (E Y − η (I⊗N) U − rhs_y).

Its continuous counterpart is `𝓛 = J − ∫₀ᵀ∫_Ω p (y_t − νΔy + v·∇y − f − ηu)`.
Integrating by parts uses:
- `δy(0) = 0`;
- `p = 0` on `∂Ω` and `p(T) = 0`;
- `div v = 0` (v constant).

Stationarity in `y`, `u` and `p` then gives the **ex21 continuous optimality
system**:

    state      y_t − νΔy + v·∇y = f + η u,                y = 0 on ∂Ω,  y(0) = y₀
    adjoint   −p_t − νΔp − v·∇p = α_t (y − y_d),          p = 0 on ∂Ω,  p(T) = 0
    gradient   α_u u + η p = 0.

The transposed operator `Eᵀ` discretises `−∂_t + Lᵀ`, and `Cᵀ = −C` on the free
DOFs discretises `−v·∇`, which is consistent with the adjoint row above.

**Reconciliation with LP.** LP write `−p_t − εΔp − w·∇p = ŷ − y` and `βu − p = 0`.
With `α_t = η = 1`, `α_u = β` and `ν = ε`, the two systems coincide exactly
under **`p_ex21 = −p_LP`** (and `u` is the same in both). T1 confirms this
symbolically, and numerically (wrong sign → 200 % error, §5).

## 2. The exact solution

Domain and data: `Ω = (0,1)²`, `T = 1`, `ν = 1/4`, `v = (1, 1/2)`,
`α_u = 1e-2`, `η = α_t = 1`. Control and tracking are full-domain (`N = M_ω = M`),
with homogeneous Dirichlet state.

    S1 = s(πx) s(πz),   S2 = s(2πx) s(πz)
    y  = cos(2t) S1
    p  = α_u sin(T − t) S2                 (p(T) = 0, p = 0 on ∂Ω)
    u  = −p/α_u = −sin(T − t) S2
    f  = y_t − νΔy + v·∇y − u              (derived from the state equation)
    y_d = y + p_t + νΔp + v·∇p             (derived from the adjoint equation, α_t = 1)

There are two shapes:
- **`sin3`** (`s = sin³`, the primary case). `y`, `p`, `f`, `y_d` and their
  gradients vanish on `∂Ω`. This makes the data compatible with the inherited
  load convention `M_elim I_h f`, which drops boundary nodal values of the data
  (`EX21_CONVECTION_VALIDATION.md` §F.2, §K.2).
- **`sin`** (`s = sin`). Here `f = πv_x sin(πz) cos(2t) ≠ 0` and
  `y_d = 2πα_u v_x sin(πz) sin(T−t) ≠ 0` on `x = 0`, so this case deliberately
  exercises that convention.

The two shapes reuse the protocol of the existing forward MMS (`--convection-mms
sin|sin3`). The shape was not chosen to force a slope: both shapes are run and
reported.

Neither `y` nor `p` is trivial, they use different spatial modes, and the
convection term is genuine. At `(0.3, 0.4)`, `t = 0`:
`|v·∇y| / |νΔy| = 1.54` for sin3 and `0.57` for sin. The global Péclet number
`|v|L/ν = 4.5`.

Cell Péclet `|v|h/(2ν)` = 0.56, 0.28, 0.14, 0.070, 0.035 for nx = 4…64. **This is
not a convection-dominated test, by design.**

**Symbolic verification** (`t2_symbolic_check.py`, SymPy, run before any
numerical run). The data are written exactly as the C++ code forms them, with
`ν`, `v`, `α_u`, `η`, `α_t` left symbolic. All three optimality residuals are
**0**, as are `p(T)` and `y`, `p` on all four sides, for both shapes. The boundary
traces of `f` and `y_d` are 0 for sin3 and the nonzero expressions above for sin.

## 3. What is measured

The driver (`--exact-oc`) runs the **production** `SolveOptimalControl` with the
SCHUR_SWEEP preconditioner. The tolerances are tightened in a driver-local policy
(outer 1e-12, inner 1e-10, spatial 1e-12); the production defaults are unchanged.

It then computes true finite-element errors by element quadrature
(`IntegrateSpatialField`, not nodal). The fields are sampled as follows:
- **state** `y_n` at `t_n`;
- **adjoint and control** at the interval midpoint `t_{n−½}` under CN (they are
  interval quantities of the DTO scheme), and at `t_n` under BE.

Norms, all relative to the exact field over the same set of time slots and
weighted by `dt`:
- `L²(0,T;L²)`: all slots;
- *int*: all slots except the last;
- *t ≤ T/2*: a fixed physical window, so it measures the same continuous region
  at every level;
- *last*: the last slot alone, absolute;
- `y(T)`: the state at the final time.

**Temporal contamination is visible at nx = 64 and is quantified, not hidden.**
1. **State: none.** The state reaches 3.00 at nx = 32→64. At nx = 32, halving
   `dt` (Nt 128 → 256) changes `y`'s error by 6.6e-4 (relative).
2. **Adjoint and control on the whole interval: contaminated at nx = 64.** Their
   order drops to 2.83 there, and `y(T)` drops to 2.78.

   The cause is the CN terminal adjoint layer (§6), which at `Nt = 256` is no
   longer negligible next to the nx = 64 spatial error.
   - On the fixed window `t ≤ T/2` the **same runs** give **3.01**.
   - At nx = 32, halving `dt` changes the interior `p` error by 1.8 % and the
     all-slot error by 3.3 %.
   - The terminal-slot error is spatially converged already at nx = 16 (§6), so
     it is temporal.
3. **Claim.** Q2 is third order in `L²(L²)` for `y` (nx 8→64), and for `p` and
   `u` on `t ≤ T/2` (nx 8→64). For `p` and `u` on the whole interval the claim
   covers nx 8→32 (3.17, 3.05).
   - **Order 3 is not claimed** for the whole-interval adjoint at nx = 32→64.
   - Removing the contamination needs Nt ≈ 512 at nx = 64, about 18 GB, which
     was judged not worth it. The window result already isolates the spatial
     order.

## 6. The CN terminal adjoint slot (sin3, nx = 16)

The terminal-slot error is spatially converged already at nx = 16: nx = 16 and
nx = 32 agree to 0.4 % at Nt = 128.

| Nt | ‖p_N − p(t_{N−½})‖ (abs.) | ord | relative | ord | p, t ≤ T/2 (spatial floor) |
|---|---|---|---|---|---|
| 16 | 3.593e-05 | – | 3.68e-01 | – | 3.37e-03 |
| 32 | 1.280e-05 | 1.49 | 2.62e-01 | 0.49 | 3.16e-03 |
| 64 | 4.190e-06 | 1.61 | 1.72e-01 | 0.61 | 3.16e-03 |
| 128 | 1.266e-06 | 1.73 | 1.04e-01 | 0.73 | 3.16e-03 |
| 256 | 3.573e-07 | 1.82 | 5.85e-02 | 0.82 | 3.16e-03 |
| 512 | 9.659e-08 | **1.89** | 3.17e-02 | **0.89** | 3.16e-03 |

**Interpretation.**
- The exact adjoint vanishes at `T`, so `|p(t_{N−½})| = O(dt)`. The last row
  of `Eᵀ` gives `(M/dt + Lᵀ/2) λ_N = ½ M r_N`. Hence `λ_N` agrees with
  `p(t_{N−½}) ≈ (dt/2) r(T)` to leading order, and the remainder is an
  `O(dt·‖L‖)` *relative* deviation.
- Measured: the **relative** terminal error decays at order → 1. The
  **absolute** error decays at an order rising 1.49 → 1.89, which is still
  pre-asymptotic and approaching 2.
- This is the DTO terminal structure the ex20 reports already documented:
  `λ_{N+1} = 0` rather than LP's imposed `p(t_f) = 0`. Here it has **no
  first-order stagnation**.
- It is the only place where CN's adjoint deviates from clean second order, and
  it is what contaminates the nx = 64 whole-interval spatial order (§4).
